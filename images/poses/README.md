# 포즈 이미지 폴더

이 폴더에 아래 이름으로 PNG를 넣으면 앱이 자동으로 사용합니다. 없는 포즈는 `base.png`가 대신 나옵니다.

| 파일 이름 | 언제 나오나 | 포즈 예시 |
|---|---|---|
| base.png | 기본 (상점 썸네일·로고 포함) | 앉은 자세 |
| morning.png | 출근 전 | 하품, 잠옷 |
| work.png | 근무 중 | 노트북 타이핑 |
| happy.png | 근무 중, 기분 좋음 | 웃는 얼굴 |
| tired.png | 행복·멘탈 낮음 | 축 처짐 |
| off.png | 퇴근 후 | 만세, 가방 |
| night.png | 야근 | 모니터 앞 |
| weekend.png | 주말 | 누워서 뒹굴기 |
| payday.png | 금요일 월급상자 개봉 후 | 놀람 |
| lunch.png | (예약) 점심 | 밥 먹기 |

## 규칙
- 배경 투명 PNG
- 캔버스 비율 1303 × 1207 (base.png와 동일), 돌 몸통 위치·크기도 최대한 동일하게 (돌 바닥선 y=544, 높이 약 440px @652×604)
- 파일 이름은 소문자 그대로
